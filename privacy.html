Privacy Policy

Last updated: January 2025

Overview

This static website processes supported media locally in your browser where technically possible. The application does not require an account, and we do not collect, store, or transmit your uploaded media files.

How Processing Works

When you upload an image or video, the file is loaded into your browser's memory. Processing occurs using browser APIs such as the Canvas API and MediaRecorder API. Your media files are not uploaded to any server for processing.

GitHub Pages hosting may serve static files (HTML, CSS, JavaScript) but should not receive uploaded media as application data. The file transfer occurs only between your device's storage and your browser's memory.

Third-Party CDN Libraries

This application may load third-party libraries from CDNs (Content Delivery Networks) for enhanced functionality. Loading a library from a CDN means your browser downloads code from that CDN — this is different from uploading your media files. No media content is sent to CDNs during processing.

Browser and Device Limitations

Processing capability depends on your device's hardware and browser implementation. Some features may be unavailable or limited on certain devices, browsers, or for large media files.

No guarantee is made that all processing occurs entirely locally if a third-party CDN library itself performs network loading. However, your media content remains on your device.

Local Storage

This website uses browser storage technologies (localStorage and IndexedDB) to maintain your theme preference and temporarily store media between page navigations. This data remains on your device and can be cleared by clearing your browser data.

Your Responsibility

You should only edit media you own or are authorized to edit. This tool is designed for legitimate media editing and cleanup purposes.

Contact

For privacy-related questions, please open an issue on the GitHub repository hosting this site.
